Two lines explaining a toaster to a 10-year-old: one vivid sentence built on a single analogy (a tiny elevator for bread), and one honest sentence about what that analogy maps and what it leaves out.

## Run it

```sh
python3 main.py
```

This writes the two-line entry to `/output/entry.txt` (291 characters, inside the 1–400 character gate).
